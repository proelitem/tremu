# SideQuest 掲載情報 — 日本語

**名前：** Tremu

**キャッチコピー：** Quest の中のガンシューティング・アーケード。本物のガンでも Touch コントローラーでも狙えます。

**説明：**

Tremu は Meta Quest 3 / 3S をガンシューティングの筐体に変えます。ゲームは目の前の大きな仮想スクリーンに
映り、自然に狙えます。Bluetooth ガン WonderFitter（M416、M17）、USB／Bluetooth のガン、あるいは
Touch コントローラーだけでも遊べます。

- **アーケードと家庭用機**：アーケード（FBNeo、MAME）、ファミコン、スーパーファミコン、NINTENDO64、
  メガドライブ、セガサターン、PlayStation 1・2、PSP、ドリームキャスト、NAOMI、ゲームキューブ、Wii、
  Xbox、Xbox 360 を、ポスター付きのカルーセルにまとめて表示。
- **PS3、Wii U、PS Vita** は連携アプリで。Tremu から起動・終了できます。
- **ガン**：専用アプリなしで WonderFitter に対応、ガンごとの取り付け設定、発射時の振動、各機種の
  GunCon やガンコントローラーをエミュレート。
- **2〜4 台のヘッドセットで一緒に**：同じ Wi-Fi でも、インターネット経由でもコード一つで。有料サーバー不要。
- **立体感**：一部の PS2、N64、Xbox 360 のゲームで立体視。スクリーンの周りは黒い背景か、実際の部屋。
- **ケーブルなしでゲームを追加**：PC やスマホのブラウザから。

Tremu は無料のオープンソース（GPL v3）で、コードは公開されています。**ゲーム、BIOS、ファームウェア、
キーは含まれていません**。ご自身のコピーを使ってください。インストールガイド：https://github.com/proelitem/tremu/blob/main/docs/install/ja.md
