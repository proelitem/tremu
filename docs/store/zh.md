# SideQuest 页面 — 中文

**名称：** Tremu

**一句话介绍：** 装进 Quest 的光枪街机厅：用真正的光枪或 Touch 手柄瞄准。

**介绍：**

Tremu 把你的 Meta Quest 3 或 3S 变成一台射击街机。游戏显示在你面前的大型虚拟屏幕上，瞄准方式
十分自然：使用 WonderFitter 蓝牙光枪（M416、M17）、USB／蓝牙光枪，或者直接用 Touch 手柄。

- **街机与主机**：街机（FBNeo、MAME）、FC、SFC、N64、MD、土星、PlayStation 1 和 2、PSP、Dreamcast、
  Naomi、GameCube、Wii、Xbox 与 Xbox 360，集中在带封面的轮播界面中。
- **PS3、Wii U 和 PS Vita**：通过我们的配套应用，在 Tremu 中启动和退出。
- **光枪**：无需 WonderFitter 官方应用即可使用，每把枪单独保存安装设置，开枪震动，模拟各主机的
  GunCon 和光枪。
- **两到四台头显一起玩**：同一 Wi-Fi，或通过互联网输入一个代码即可，不需要付费服务器。
- **立体效果**：部分 PS2、N64 和 Xbox 360 游戏支持立体画面；屏幕周围可选黑色背景或真实房间。
- **无需数据线添加游戏**：用电脑或手机浏览器即可。

Tremu 免费且开源（GPL v3），代码公开。**不包含任何游戏、BIOS、固件或密钥**，请使用你自己的副本。
安装指南：https://github.com/proelitem/tremu/blob/main/docs/install/zh.md
