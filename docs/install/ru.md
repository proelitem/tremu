# Установка Tremu

[English](en.md) · [Deutsch](de.md) · [Español](es.md) · [Français](fr.md) · [日本語](ja.md) · **Русский** · [中文](zh.md)

Tremu превращает Meta Quest 3 или 3S в игровой автомат-тир: игры показываются на большом
виртуальном экране, а целиться можно пистолетом WonderFitter или контроллерами Touch. Tremu **не
содержит игр, BIOS, прошивок и ключей**: используйте собственные копии.

## 1. Подготовка шлема

1. Включите **режим разработчика**: в мобильном приложении Meta Horizon откройте свой шлем, затем
   «Настройки шлема» › «Режим разработчика» (нужна бесплатная организация разработчика Meta).
2. Установите на ПК программу для установки приложений: [Meta Quest Developer Hub](https://developers.meta.com/horizon/documentation/android-apps/meta-quest-developer-hub/)
   или [SideQuest](https://sidequestvr.com/). Подключите шлем по USB и разрешите отладку по USB в шлеме.

## 2. Установка Tremu

Установите `tremu.apk` этой программой (перетащите APK на шлем). При первом запуске Tremu попросит:

- **Доступ ко всем файлам**: разрешите. Tremu читает игры из `Download/Roms` и хранит свои
  файлы в папке `Tremu`.
- **Устройства поблизости (Bluetooth)**: разрешите, это нужно для пистолета WonderFitter.

Tremu появится в «Библиотека» › «Неизвестные источники».

## 3. Добавление игр

| Что | Куда, в шлеме |
|---|---|
| Игры | `Download/Roms/<консоль>`, по папке на консоль (например, `Download/Roms/ps1`) |
| Аркадные игры MAME (Area 51, CarnEvil…) | `Download/Roms/mame/<игра>` (в распакованном виде, вместе с `.chd`) |
| Игры Wii U, PS3, PS Vita | `Download/Roms/wiiu`, `Download/Roms/ps3`, `Download/Roms/vita` |
| BIOS (PS2, Saturn, Mega-CD…) | `Tremu/bios` (PS2: `Tremu/bios/pcsx2/bios`) |
| Системные файлы Xbox | `Tremu/Xbox/system` |
| Обложки | `Tremu/Banner` (недостающие скачиваются сами) |

Без кабеля: внизу карусели показаны «Добавить игры: http://…» и код. Откройте этот адрес на ПК или
телефоне в той же сети Wi-Fi и перетащите файлы — Tremu разложит их сам.
Если не хватает файла (BIOS, жёсткого диска), сообщение говорит, какого именно и куда его положить.

## 4. Дополнительные приложения

Tremu сам эмулирует аркады, NES, SNES, N64, Mega Drive, Saturn, PS1, PS2, PSP, Dreamcast,
GameCube, Wii, Xbox и Xbox 360. Четыре системы работают через отдельное приложение: Tremu открывает
его, а в конце игры оно возвращает в карусель.

| Для | Приложение | Исходный код |
|---|---|---|
| PS3 | ARMSX3 (`com.armsx3`) | [proelitem/ARMSX3](https://github.com/proelitem/ARMSX3) |
| Wii U | Cemu (`info.cemu.cemu`) | [proelitem/Cemu](https://github.com/proelitem/Cemu), ветка `tremu` |
| PS Vita | Vita3K (`org.vita3k.emulator`) | [proelitem/Vita3K](https://github.com/proelitem/Vita3K), ветка `tremu` |
| Time Crisis VR | `org.timecrisis.quest` | [proelitem/time-crisis-vr](https://github.com/proelitem/time-crisis-vr) |

Нужны **именно эти сборки**: официальные не получают игру, выбранную в Tremu, и не возвращаются в
карусель. Если официальная версия уже установлена (особенно ARMSX3), **сначала удалите её**: Android
не заменит её сборкой с другой подписью.
Без приложения плитка игры всё равно показывается, и Tremu подскажет, что установить.
Прошивку PS3, прошивку PS Vita (`.PUP`, в `Download/Roms/vita`) и ключи Wii U вы предоставляете сами.

## 5. Пистолет WonderFitter

Включите пистолет: Tremu сам найдёт его по Bluetooth, официальное приложение WonderFitter не нужно.
Пистолет принимает **только одно приложение одновременно**: закройте официальное приложение, если оно
открыто. Настройки крепления (угол, смещения) находятся в меню Tremu и запоминаются для каждого
пистолета. Без пистолета целятся контроллеры Touch.

Wiimote (игры Wii): только через **DolphinBar** от Mayflash, подключённый к шлему по USB.

## 6. Игра вместе

Одна сеть Wi-Fi: один шлем запускает игру и выбирает меню › Мультиплеер › «Создать (Wi-Fi)»;
на другом в карусели появится плитка «Войти: …». На обоих шлемах нужны **одна и та же
версия Tremu и один и тот же файл игры**. В играх MAME хост перезапускает игру с начала и ждёт
второго игрока: партия начинается вместе.

Через Интернет: «Создать в Интернете» показывает код для второго игрока (меню › Войти по коду).
Платных серверов нет: если код не появляется, откройте на роутере UDP-порт 47617 (или включите UPnP).

## Выход и меню

Кнопка меню левого контроллера: настройки игры. Удержание 1,5 с в игре, запущенной из Tremu
(PS3, Wii U, Vita, Time Crisis VR): возврат в карусель.
